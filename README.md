# CC Lab: QR-поздравления

Покупатель сканирует QR с открытки, заполняет форму, проверяет демо и активирует страницу. Активная страница хранится 7 дней, затем текст и фото удаляются.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env   # заполните ADMIN_PASSWORD и SESSION_SECRET
npm start
```

- Сайт: `http://localhost:3000`
- Админка: `http://localhost:3000/admin`
- Тесты: `npm test`

## Структура

| Папка | Что внутри | Кто правит |
|---|---|---|
| `raiko/` | Шаблоны открыток: список, стили, первый экран, украшения, демо-картинки. См. [raiko/README.md](raiko/README.md) | Дизайн |
| `src/` | Сервер: маршруты, база, коды и тарифы (`tiers.js`), страницы сайта и админки | Разработка |
| `public/` | Стили сайта и админки, скрипты браузера, иконка | Разработка |
| `test/` | Тесты (`npm test`) | Разработка |

## Работа в админке

1. «Шаблоны и музыка»: загрузите по 3 мелодии на шаблон.
2. «Партии кодов»: выберите тариф (базовый или премиум) и количество.
3. Откройте партию, нажмите «Печать QR» и напечатайте через Ctrl+P.

## Продакшен

- До печати задайте постоянный домен в `PUBLIC_BASE_URL`: он зашит в каждый QR-код.
- Нужен сервер с постоянным диском: в `DATA_DIR` лежат база, фото и песни. Делайте резервные копии этой папки.
- Установите ffmpeg: без него песни хранятся и отдаются в исходном размере.
- Поставьте приложение за nginx или Caddy с HTTPS и включите `TRUST_PROXY=1`.

Контакты на последней странице задаются в `src/brand.js`.
