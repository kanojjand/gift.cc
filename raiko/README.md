# Папка Райко: дизайн открыток

Здесь всё оформление шаблонов. Работай только в этой папке: остальной код (`src/`, `public/`, `test/`) отвечает за коды, оплату, фото и админку, его трогать не нужно.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `card.js` | Разметка страницы открытки: порядок блоков, имя, текст, фото, последняя страница с контактами |
| `assets/js/card.js` | Анимации в браузере: открытие, частицы, появление слов, подгонка длинного имени, музыка |
| `templates.js` | Список шаблонов: название, описание, цвета, шрифты, частицы, подписи, обычный или премиум |
| `texts.js` | Готовые тексты поздравлений для формы: поводы, по 3 варианта на русском и казахском, отдельно для базового и премиум-кода |
| `assets/css/card-base.css` | Общие стили всех открыток: экран открытия, текст, фото, последняя страница с контактами |
| `assets/css/<id>.css` | Стили одного шаблона, например `gold.css` для «Чёрного золота» |
| `gates.js` | Первый экран каждого шаблона (конверт, двери, занавес и т. д.) и разделители |
| `decor.js` | Фон и украшения на открытке (марки, цветы, луна, орнамент), заключительные фразы |
| `assets/demo/1.svg` … `5.svg` | Картинки вместо фото на демо-страницах |

## Как посмотреть результат

Один раз:

```bash
npm install
cp .env.example .env
```

В `.env` впиши любой `ADMIN_PASSWORD` и `SESSION_SECRET` длиной от 32 символов.

Потом каждый раз:

```bash
npm run dev
```

Открой `http://localhost:3000/demo/gold` (вместо `gold` любой id шаблона). Список всех шаблонов на `http://localhost:3000/`. После правки CSS обнови страницу; после правки `.js` сервер перезапустится сам.

## Как добавить новый шаблон

1. Добавь объект в `templates.js` (скопируй соседний и поменяй `id`, тексты и цвета).
2. Создай `assets/css/<id>.css`.
3. Добавь первый экран в `gates.js` (объект `GATES`) и украшения в `decor.js` (`BACKDROPS`), если нужны.

Если ошибёшься в `templates.js` (нет файла стилей, неправильный цвет, повторился id), сервер не запустится и напишет, что именно не так.

## Скорость на телефоне

Открытку открывают по QR, обычно с мобильного интернета, поэтому первый экран должен появляться сразу:

- Стили `card-base.css` и `<id>.css` сервер встраивает прямо в страницу, отдельного запроса за ними нет. Правишь CSS как раньше, после правки просто обнови страницу.
- Шрифты Google грузятся параллельно и не задерживают первый экран. Пока шрифт не пришёл, имя на первом экране скрыто и потом плавно проявляется (не дольше 1,2 секунды). Если имя в первом экране нового шаблона стоит не в `.gate-title`, добавь его класс в правило `.card.fonts-wait` в `card-base.css`.
- Не добавляй в стили картинки через `url(...)` и `@import`: встроенные стили их не найдут. Украшения рисуй в SVG в `gates.js` и `decor.js`, как сейчас.
- Фото начинают грузиться в момент открытия, пока человек читает текст.

## Правила

- Шрифты только с казахскими буквами (ә, ғ, қ, ң, ө, ұ, ү, һ, і). Проверь на шаблоне «Шаңырақ».
- Имя получателя может быть длинным: проверь на «Александра-Виктория».
- Смотри с телефона шириной 360 px, открытки открывают в основном с телефона.
- `id` шаблона не меняй, если по нему уже напечатаны открытки.
- Готовые тексты проверяй в форме на обоих языках; текст не длиннее 1000 символов, иначе сервер не запустится и напишет, где ошибка.
- Перед отправкой изменений запусти `npm test`.

## Служебное, не удалять

Это нужно сайту, а не дизайну. Оформлять можно как угодно, но не удаляй и не переименовывай:

- в `card.js` окно `confirm-dialog` с кнопкой `confirm-yes` и полем `confirm-error`: через них покупатель активирует открытку;
- атрибуты `data-code` и `data-track` у `.card`;
- в `assets/js/card.js` строку с `sendBeacon(...opened)`: она считает, сколько раз открытку открыли.

Если тесты после правки упали, значит что-то из этого задето.
