# Папка Райко: дизайн открыток

Здесь всё оформление шаблонов. Работай только в этой папке: остальной код (`src/`, `public/`, `test/`) отвечает за коды, оплату, фото и админку, его трогать не нужно.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `themes/<id>.js` | Новые шаблоны, один файл на шаблон: первый экран, фон, разделитель и история после открытия (`story`) |
| `story.js` | Общие части историй: фото, которое открывается на весь экран, письмо с подписью, песня, кнопки финала |
| `paper.js` | Помощники для SVG-украшений: еловые ветки, угловые украшения |
| `references.md` | Описания для генерации картинок-референсов по каждому новому шаблону |
| `card.js` | Разметка страницы открытки: порядок блоков, имя, текст, фото, последняя страница с контактами |
| `assets/js/card.js` | Анимации в браузере: открытие, частицы, появление слов, подгонка длинного имени, музыка |
| `templates.js` | Список шаблонов: название, описание, цвета, шрифты, частицы, подписи |
| `texts.js` | Готовые тексты поздравлений для формы: поводы, по 3 коротких (`short`) и 3 развёрнутых (`long`) варианта на русском и казахском |
| `assets/css/card-base.css` | Общие стили всех открыток: экран открытия, текст, фото, последняя страница с контактами |
| `assets/css/<id>.css` | Стили одного шаблона, например `gold.css` для «Чёрного золота» |
| `gates.js` | Первый экран каждого шаблона (конверт, двери, занавес и т. д.) и разделители |
| `decor.js` | Фон и украшения на открытке (марки, цветы, луна, орнамент), заключительные фразы |
| `assets/demo/1.svg` … `5.svg` | Картинки вместо фото на демо-страницах |

## Как посмотреть результат

Один раз:

```bash
npm install
cp .env.example .env
```

В `.env` впиши любой `ADMIN_PASSWORD` и `SESSION_SECRET` длиной от 32 символов.

Потом каждый раз:

```bash
npm run dev
```

Открой `http://localhost:3000/demo/newyear` (вместо `newyear` любой id шаблона). Список всех шаблонов на `http://localhost:3000/`. После правки CSS обнови страницу; после правки `.js` сервер перезапустится сам.

## Песня

Покупатель может вставить ссылку на песню из YouTube, Spotify, Apple Music или Яндекс Музыки. Тогда на первом экране после открытия, под именем, стоит блок `.hello-song`: подпись `.song-label`, официальный плеер сервиса в рамке `.song-player` и подсказка `.song-hint`. В демо на месте плеера заглушка `.song-demo`.

- Подпись по умолчанию «Эта песня — для тебя». Свою можно задать шаблону в `templates.js`: `labels.song`.
- Плеер оформлять можно (рамка, тень, отступы), но не прятать, не уменьшать YouTube меньше 200 px в высоту и ничего не класть поверх: это условия сервисов. Плеер должен остаться на первом экране под именем: YouTube разрешает включать песню сам только когда плеер виден.
- Плеер грузится, когда человек касается первого экрана (бант, шар, замок). YouTube и Spotify включаются сами, как только открытка раскрылась. Apple Music и Яндекс так не умеют, там сразу видна подсказка «Нажми ▶».
- iPhone не даёт встроенным плеерам играть со звуком без нажатия на сам плеер. Если песня за 5 секунд не заиграла, появляется подсказка.
- Для песни из YouTube покупатель может выбрать момент начала (например, припев). Остальные сервисы без подписки играют свой отрывок, там момент не выбирается.
- Демо: `/demo/newyear`, нажми на шар.

## Палитры

У каждого нового шаблона 4 палитры, покупатель выбирает цвет в форме и может переключать его в демо. Палитра — это 6 цветов в `templates.js`, они приходят в CSS переменными:

| Переменная | Что это |
|---|---|
| `--bg`, `--bg2` | Фон и второй тон фона (для градиентов) |
| `--ink` | Цвет текста |
| `--accent`, `--accent2`, `--accent3` | Акценты: золото, лента, конфетти, сердца… |

В CSS шаблона не пиши цвета напрямую, бери переменные: тогда шаблон сам перекрашивается в любой палитре. У карточки есть класс `tone-light` или `tone-dark` (по светлоте `--bg`), им можно поправить стекло и тени для светлых палитр. Демо в нужном цвете: `/demo/newyear?p=frost`.

## Как добавить новый шаблон

1. Добавь объект в `templates.js` с палитрами (скопируй соседний и поменяй `id`, тексты и цвета).
2. Создай `assets/css/<id>.css`.
3. Создай `themes/<id>.js` по образцу соседнего и подключи его в `themes/index.js`.

Если CSS-анимация меняет `transform` у SVG-фигуры, у которой есть атрибут `transform` (положение), анимация затрёт положение и фигура уедет в угол. Оборачивай такую фигуру в `<g transform="...">` и анимируй внутреннюю.

Если ошибёшься в `templates.js` (нет файла стилей, неправильный цвет, повторился id), сервер не запустится и напишет, что именно не так.

## Скорость на телефоне

Открытку открывают по QR, обычно с мобильного интернета, поэтому первый экран должен появляться сразу:

- Стили `card-base.css` и `<id>.css` сервер встраивает прямо в страницу, отдельного запроса за ними нет. Правишь CSS как раньше, после правки просто обнови страницу.
- Шрифты Google грузятся параллельно и не задерживают первый экран. Пока шрифт не пришёл, имя на первом экране скрыто и потом плавно проявляется (не дольше 1,2 секунды). Если имя в первом экране нового шаблона стоит не в `.gate-title`, добавь его класс в правило `.card.fonts-wait` в `card-base.css`.
- Не добавляй в стили картинки через `url(...)` и `@import`: встроенные стили их не найдут. Украшения рисуй в SVG в `gates.js` и `decor.js`, как сейчас.
- Фото начинают грузиться в момент открытия, пока человек читает текст.

## Правила

- Шрифты только с казахскими буквами (ә, ғ, қ, ң, ө, ұ, ү, һ, і). Список проверенных шрифтов в начале `templates.js`.
- Имя получателя может быть длинным: проверь на «Александра-Виктория».
- Смотри с телефона шириной 360 px, открытки открывают в основном с телефона.
- `id` шаблона не меняй, если по нему уже напечатаны открытки.
- Готовые тексты проверяй в форме на обоих языках; текст не длиннее 1000 символов, иначе сервер не запустится и напишет, где ошибка.
- Перед отправкой изменений запусти `npm test`.

## Служебное, не удалять

Это нужно сайту, а не дизайну. Оформлять можно как угодно, но не удаляй и не переименовывай:

- в `card.js` окно `confirm-dialog` с кнопкой `confirm-yes` и полем `confirm-error`: через них покупатель активирует открытку;
- атрибуты `data-code` и `data-track` у `.card`;
- в `assets/js/card.js` строку с `sendBeacon(...opened)`: она считает, сколько раз открытку открыли.

Если тесты после правки упали, значит что-то из этого задето.
